# Hotel Booking Confirmation Page

A responsive hotel booking confirmation page built as a solution to a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## 🛠️ Built With

- HTML5
- CSS3
- Responsive Design

## 📱 Responsive Design

The original challenge provided designs for **320px** and **1440px** screens.

I went beyond the required breakpoints and added responsive styles for:

- 320px
- 481px
- 769px
- 1025px
- 1440px
- 5102px

The page is designed to adapt smoothly from small mobile screens to very large displays.
